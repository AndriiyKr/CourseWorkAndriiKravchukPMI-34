# CourseWorkAndriiKravchukPMI-34

Цей проєкт розроблений як курсова робота. Він дозволяє користувачам інтерактивно створювати графи (орієнтовані та неорієнтовані), редагувати їх властивості та запускати різноманітні алгоритми теорії графів для аналізу.

**Спробувати можна тут:** [https://graphinfo.pythonanywhere.com/](https://graphinfo.pythonanywhere.com/)

---

## Основний функціонал

### Редактор графів
* Додавання, переміщення та видалення вершин.
* Створення ребер (включно з дугами, петлями та кратними ребрами).
* Редагування ваги ребер.
* Зміна назв вершин.
* Підтримка орієнтованих та неорієнтованих графів.

### Алгоритми та Аналіз
Бекенд використовує бібліотеку `NetworkX` для розрахунків, але також використовує і власні функції, які дають покроковий результат.

1.  **Базові характеристики:**
    * Матриця суміжності та матриця інцидентності.
    * Списки суміжності.
    * Степені вершин (вхідні/вихідні для орієнтованих).
    * Перевірка на зв'язність та пошук компонент зв'язності.
    * Пошук циклів та обхвату графа.

2.  **Пошук шляхів:**
    * **Алгоритм Дейкстри:** Пошук найкоротшого шляху між двома вершинами.
    * **Алгоритм Флойда-Воршелла:** Пошук найкоротших шляхів між усіма парами вершин (з покроковою візуалізацією матриць).

3.  **Обходи графа:**
    * **BFS** (Пошук у ширину) з протоколом обходу.
    * **DFS** (Пошук у глибину) з протоколом обходу.

4.  **Складні задачі:**
    * Пошук **Ейлерового** циклу або шляху.
    * Пошук **Гамільтонового** циклу або шляху.
    * **Розфарбування графа** (жадібний алгоритм).
    * Знаходження хроматичного числа, клікового числа та числа незалежності.

## Технічний стек

### Frontend
* **React.js** (Vite) — для побудови інтерфейсу користувача.
* **SVG** — для рендерингу графічних елементів (вершин та зв'язків).
* **Tailwind CSS** — для стилізації компонентів.

### Backend
* **Python 3.x**
* **Django & Django REST Framework** — API для обробки запитів.
* **NetworkX** — для роботи з графами та алгоритмами.
* **NumPy** — допоміжні обчислення для матриць.
